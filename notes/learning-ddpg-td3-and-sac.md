## Learning DDPG, TD3, and SAC

## Deep Deterministic Policy Gradient (DDPG)
- off-policy, model-free algorithm designed for environments where the action space is conitnuous.
- DDPG is an actor-critic method where the actor estimates the policy using the policy gradient and the critic evaluates the policy produced by the actor using the Q function.
- uses the policy network as an actor and a deep q network as a critic
- DDPG tries to learn a deterministic policy instead of a stochastic policy.
- A deterministic policy tells the agent to perform one particular action in a given state. See [RL Foundations](./foundations.md)

$$
    a = \mu(s)
$$
- A stochastic policy maps the state to the probability distribution over the action space. See [RL Foundations](./foundations.md)

$$
    a \sim \pi(s)
$$

### Actor

- The actor is basically the policy network.
- Learns the mapping between the state and action.
- The actor learns the optimal policy that gives the maximum return.
- The actor uses the policy gradient method to learn the optimal policy.

### Critic
- The critic is basically the value network.
- Evaluates the action produced by the actor network.
- The action can be evaluated using the Q function
- Q value
  - **High**: The action performed is good, that is the expected return is high when the action a is performed in state s.
  - **Low**: The action performed is bad as the expected return is low when the action a is performed in state s.
- based on the feedback of the critic network, the actor tries to perform a different action.
- to learn the Q function, the critic uses a deep Q network. See [DQN](./deep-q-networks-and-variants.md)

## Actor network
- The actor netork is the policy network
- uses the policy gradient to compute the optimal policy.
- the parameter of the actor network is $\phi$
- the action is given by:
$$
    a = \mu_{\phi}(s)
$$
- since we are using a deterministic policy, we need to take care of the exploration exploitatin dilemma. Since we have a continous action space, we can just ad some noise.
- The noise is generated by a process called the Ornstein-Uhlenbeck random process.

$$
    a = \mu_{\phi}(s) + \mathcal{N}
$$
- The critic gives good feedback when the action produced by the actor has a maximum Q value
- So, the objective function of the actor network is to generate an action that maximizes the Q value produced by the critic network.

$$
    J(\phi) = Q_{\theta}(s, a)
$$

- we maximize the the objective function by performing gradient ascent.

$$
    \phi = \phi + \alpha \nabla_{\phi}J(\phi)
$$

- Instead of udpating the parameter $\phi$ for a single state s,we sample K numberof states fromt the replay buffer $\mathcal{D}$ and update the parameter.

$$
    J(\phi) = \frac{1}{K}\sum_{i} Q_{\theta}(s_i, \mu(s_i))
$$

- the parameter of the target actor network is updated by soft replacemnt


$$
    \phi' = \tau\phi + (1 - \tau)\phi'
$$

- The main actor network parameter is representd by $\phi$

## Twin Delayed DDPG
- DDPG critic network overestimates the target Q value.
- The overestimation causes stability issues to our policy which may cause it to not converget to local optima
- TD3 proposes three features to combat this;
  - Clipped double Q learning
  - Delayed policy updates
  - Target policy smoothing

### Clipped double Q learning
- We use two main critic networks to compute the Q value and two target critic newtorks to compute the target value.
- We compute tow target Q values using two target critic networks and use the minimum value of the these two while computing the loss. This prevents overestimating the target Q value.
- We define two main critic networks that compute $Q_{\theta_{1}} (s, a)$ and $Q_{\theta_{2}} (s, a)$
- We also define two target critic networks that compute $Q_{\theta'_{1}} (s, a)$ and $Q_{\theta'_{2}} (s, a)$

### Delayed policy updates
- We delay updating the parameter of the actor network. 
- The critic network parameter is updated at every step of the episode.
- actor network parameter is updated only after two steps of the episode.
- this ensures that the critic netork estimates the correct Q values.

### Target policy smoothing
- DDPG method produces different target values even for the same action. the variance for the same action is high. We add some noise to reduce the variance.
- The target value is given by

$$
    y = r + \gamma \min ( Q_{\theta'_{1}}(s', \mu_{\phi'}(s')), Q_{\theta'_{2}}(s', \mu_{\phi'}(s')) )
$$

- we add some noise to the action a which becomes $\~{a}$

$$
    \~{a} = \mu_{\phi'}(s') + \epsilon \quad \epsilon \sim (\mathcal{N}(0, \sigma), -c, +c)
$$

- the noise is clipped so that we can keep the target close to the actual action.

## Soft actor critic (SAC)
- uses a stochastic policy unlike the TD3 algorithm
- based on the concept of entropy
- Entropy is a measure of randomness of a variable.
- Entropy tells us the uncertainity or unpredictabiity of the random variable and is donoted by $\mathcal{H}$
- If a random variable always gives the same value all the time, then it has low entropy since there is no randomness.
- If the entropy of the policy is high, it means that the policy performs differnt actions every time.
- Increasing the entropy of the policy promotes exploration.
- The objective function in reinforcement learning is

$$
    J(\phi) = \mathbb{E}_{\tau \sim \pi_{\phi}}\left[ R(\tau) \right]
$$

- The return is given by

$$
    R(\tau) = \sum_{t=0}^{T-1} r_t
$$

- so we have,

$$
    J(\phi) = \mathbb{E}_{\tau \sim \pi_{\phi}}\left[ \sum_{t=0}^{T-1} r_t \right]
$$

- The slightly modfied objective function in SAC is 

$$
    J(\phi) = \mathbb{E}_{\tau \sim \pi_{\phi}}\left[ \sum_{t=0}^{T-1} r_t  + \alpha \mathcal{H}(\pi(. \mid s_t))  \right]
$$

- Instead of maximizing only the reward, we maximize the entropy also.
- maximizing the entropy encourages exploration.
